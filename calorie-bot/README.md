# Бот-калькулятор калорий по фото

Telegram-бот: присылаете фото еды — он определяет блюда, примерный вес порций, калории и БЖУ (анализ делает Claude). Ведёт дневник за день.

**Команды:** фото (можно с подписью «порция 300 г»), текст «овсянка 200 г с бананом», `/today` — итог за сегодня, `/undo` — удалить последнюю запись.

## Что понадобится
1. **Токен Telegram-бота** — напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **Ключ Anthropic API** — https://platform.claude.com → API Keys (нужен пополненный баланс; одно фото стоит примерно 1–3 цента).
3. Python 3.10+.

## Запуск
```bash
cd calorie-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export ANTHROPIC_API_KEY="sk-ant-..."
python bot.py
```
Бот работает, пока запущен скрипт. Чтобы он работал круглосуточно, разместите его на VPS или хостинге (Railway, Render, Fly.io и т.п.) с этими же переменными окружения.

Необязательные переменные: `CLAUDE_MODEL` (по умолчанию `claude-opus-5-5`; `claude-haiku-5-5` — намного дешевле, но менее точно), `DB_PATH` (файл дневника, по умолчанию `calories.db`).

> Оценка по фото приблизительная (±20–30%): скрытое масло, соусы и размер порции сложно увидеть. Указывайте вес в подписи, если знаете его.
